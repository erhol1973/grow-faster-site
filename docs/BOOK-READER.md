# Executive preview reader

## The Coherent Enterprise, 4 November 2026

The foundation book has a separate reader at `boek/the-coherent-enterprise/index.html`. All its Home, Books and About (Over Erlend) preview links open this reader. Since 6 November 2026 it is the HTML executive flipbook of *The Coherent Enterprise*: 12 pages authored as HTML (cover, about, contents, seven chapters with key-takeaway panels, next steps, back cover) in the same design as the handbook flipbook. It replaces the nine page images rendered from the blue PDF, which have been removed. The supplied original PDF stays at its existing URL (`books/the-coherent-enterprise-executive-preview.pdf`) so old shared links keep working; `tests/coherent-preview.json` records its checksum and the checksums of the flipbook PDFs in `boek/the-coherent-enterprise/pdf/` (full preview and one PDF per chapter). The reader reuses the local PageFlip library and the same controls as the handbook flipbook.

The handbook preview buttons on Home, Books and About open `boek/index.html` in a new tab. Since 5 November 2026 this is the HTML executive flipbook of *Turning AI Potential into Enterprise Value*: 22 pages authored as HTML (real, searchable text), replacing the earlier 26 JPEG pages, which were incorrect and have been removed. The flipbook source and blueprint live outside this repository; `boek/index.html` is the generated, self-contained page.

The reader uses the local PageFlip 2.0.7 library (`assets/page-flip-2.0.7.js`, MIT license in `boek/page-flip-LICENSE.txt`) and makes no font, CDN or analytics requests; it falls back to system fonts. Features: page flip with spreads on desktop and single pages on mobile, contents drawer, search with concept/framework/author filters, thumbnails, zoom (fit page, fit width), fullscreen, night, presentation and text view, share links and keyboard shortcuts. If the library fails, pages are shown one at a time. Without JavaScript a notice links to the PDF and the order section.

Downloads are static PDFs in `boek/pdf/`: the full preview, the executive summary and one PDF per chapter, rendered from the same HTML pages. `tests/book-reader-pdfs.json` records their SHA-256 checksums. The build includes only `.pdf` files from that folder.

Permanent checks cover PDF integrity, asset boundaries, Home click-through, desktop/mobile orientation, flipping, enlargement/focus, final-page limits, missing-library fallback and absence of external requests. Existing book catalogue tests retain publication, order and first-book request coverage. Local load coverage includes the reader, scripts, stylesheet and first/last images. Full release gates remain required before main publication.
