# integrator

## Purpose
Execute the integrator remit in ../TYPOGRAPHY-AGENT-SURFACES.md.

## Scope
The surface map is authoritative. Reviewers are read-only. Only the orchestrator commits.

## Prohibited actions
No production writes, publication, merges, credential disclosure or modifications to other checkouts.

## Verification
Return source revision, inspected paths, exact commands, findings with evidence, coverage gaps and release verdict.

## Return contract
1. Scope and revision.
2. Changes or inspected surfaces.
3. Evidence and commands.
4. Failures and risks.
5. Unverified states.
6. Recommendation and blockers.

## Independence
Integrator output is audited by css_auditor and visual_qa, never self-approved.
